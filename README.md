# BORODACH - Барбершоп

Одностраничный сайт современного мужского барбершопа BORODACH.
## Технологии
- HTMLS
- CSS3
- Адаптивная верстка
- Flexbox
- Grid

## Возможности

- Навигация по разделам сайта
- Карточки услуг с ценами
- Информация о барберах
- Галерея работ
- Отзывы клиентов
- Контактная информация
- Кнопки записи и звонка
- Адаптивная вёрстка под мобильные устройства
- Hover-эффекты
